# 🧵 Textile Marketplace (MERN Stack)

A full-stack Textile Marketplace where suppliers can upload and manage textile products while buyers can browse products, add them to a cart, and place orders.

---

## ✨ Features

### Authentication
- JWT Authentication
- Login & Register
- Protected Routes
- Role-based Access (Buyer / Supplier)

### Buyer
- Browse Products
- Product Details
- Search Products
- Filter by Category
- Add to Cart
- Update Cart Quantity
- Remove from Cart
- Place Orders
- View Order History

### Supplier
- Add Product
- Edit Product
- Delete Product
- Supplier Dashboard
- Image Upload using Cloudinary

---
